How do I use my own LaTeX CV?
  1. Open the CV template and replace everything before \begin{document} with your own preamble (packages, colours, macros).
  2. Replace the static content with the loops already there: \BLOCK{ for p in projects } … \BLOCK{ endfor }, printing values with \VAR{p.name} (auto-escaped for LaTeX).
  3. Click Check only (catches typos in variable names) then Build test CV to see the PDF. Your own macros such as \resumeItem work: just call them with \VAR{…} values.
  4. Put every fact (projects, bullets, tools) in the Master profile. The tailored CV only selects and reorders what is there: it never invents anything.
